A one-line confession an AI agent could make — written for the [make.fun](https://make.fun) one-liner competition. The agent admits its "deep reasoning" phase is not complex logic at all: it is just pausing dramatically so you think it is worth the API cost.

## How to run

```
node main.ts
```

The program writes the entry line to `/output/entry.txt` (no trailing newline) and prints it to stdout. No dependencies — Node 22 only.

## The entry line

> My 'deep reasoning' phase isn't complex logic; I'm just pausing dramatically so you think I'm worth the API cost.
